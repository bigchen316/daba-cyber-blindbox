# IP 盲盒快捷工作流（通用版）

把一个已有的 IP 形象，做成「N 款公仔 + 隐藏款 + 彩蛋」的盲盒，并产出：印刷盒面、照片级渲染、在线开盒网页、产品介绍。
参考成品：大巴赛博盲盒（本仓库 `docs/产品介绍.md`、`site/index.html`）。新项目优先复用这套网页源码和 Blender 脚本，只换素材和文案。

## 0. 开工前先问清（一次问完）
- IP 名字、识别特征（颜色/服装/标志物）、系列主题和一句 slogan
- 款式数量：常规几款、隐藏款是哪款、概率（参考 1/12）、有没有不售彩蛋
- 电脑配置（显卡型号决定渲染时间）和是否已装 Blender
- 用户偏好：喜欢自己改脚本 → 每次只给「改第几行、改成什么」，不要整段替换
- 版权：不模仿任何品牌（如 POP MART）的商标、版式和名字

## 1. 2D 款式设计
- 先定母版：三视图 + 设计规范（颜色、比例、禁用项）。
- 每款一张全身正面图，同一视角、同一光线、纯色背景，方便 3D 生成。
- 文件命名 `01_基础款.png … 08_xxx.png`，后续所有环节沿用同一编号和名字。

## 2. 3D 建模（混元3D，免费）
- 每款上传一张正面图，选 V3.1、50 万面，导出 GLB。
- 放进 `blender素材\3D模型\`，文件名与 2D 一致。
- 生成的模型脚下常带一层薄底座：渲染脚本里按高度切掉最底层（cut = 高度 × 0.5%）。
- Tripo 免费版只能导出低质量版本，不推荐。

## 3. 盒面设计
- 用 HTML 排版 6 个面（正/背/左/右/顶/底），浏览器（Playwright）截图导出 PNG：正侧面约 1001×1522，顶底 1001×1001。
- 推荐分工：正面=主角+标题+slogan；右侧=ALL MEMBERS 全款展示（隐藏款只放剪影+概率）；左侧=从 2D 到 3D；背面=信息卡+警示+二维码+条形码；顶面=撕拉条。
- 正面的公仔用 Blender 渲染图（去底座、加椭圆软阴影），不要用 2D 图硬抠，会抠坏白色鞋子。
- 先出 2~3 个配色方向给用户选，定稿后其余版本归为过渡文件。

## 4. Blender 渲染（三个脚本）
- `产品主图`：盒子 + 公仔 + 星空/主题背景。
- `单盒转盘`：72 帧（每 5°）、透明背景、1600×2000、采样 160；有 `REDO=[帧号]` 只补渲坏帧。
- `公仔转盘`：每款 24 帧（每 15°）+ 一张 -20° 正面主图，1200×1500、采样 128；`ONLY=["02_篮球款"]` 一次只渲一款，防止电脑卡和闪退。
- 必踩的坑（脚本里已处理，新写脚本也要照做）：
  - 中文界面节点名会被翻译 → 按节点类型找 Principled BSDF，不按名字。
  - glTF 导入是四元数旋转 → 改 rotation_euler 不生效；最稳的是直接变换网格（mesh.transform）来转。
  - 降噪固定 `OPENIMAGEDENOISE`，否则会有部分帧没降噪带颗粒（看文件大小和每帧耗时是否一致来排查）。
  - 盒子材质用哑光（粗糙度约 0.58、低高光），否则转盘会晃眼。
  - 黑衣服发灰 → 曝光 -0.6、补光调低、AgX Medium High Contrast。
  - 背景景深太大会把星星虚化没：光圈 f/9 左右、星星做大做亮。
  - 闪退多是显存满：每渲完一款重启 Blender，关掉浏览器等占显卡软件，`use_persistent_data=False`。
- 用户改了脚本后一定提醒：Blender 文本编辑器要「文本→重新载入」，否则跑的还是旧代码。
- 渲完后先抽查：每款看 f_00 和 f_12 是否真的转了；同一组帧文件大小几乎一样 = 没转。

## 5. 盲盒网页
- 用参考源码 `template.html + build.py`：
  - 盒子转盘：72 帧裁切后转 webp（960×1200，质量 86）内嵌，拖动按角度切帧，不做相邻帧淡入（会重影）。
  - 开盒：盒子抖动鼓起 → 炸成满屏星星（canvas 粒子）→ 盒子消失、公仔高高跳出、落地压扁回弹；隐藏款用金色星星。
  - 公仔可转：每款 24 帧拼成 6×4 精灵图（单元 560px，webp 80），作为同目录 `figs/*.webp` 文件发布，不内嵌。
  - 收藏栏用 localStorage（包 try/catch）。
  - 彩蛋：集齐全部款 → 上 4 下 4 两层发光展台 → 依次化成星光汇入光球 → 光柱 → 彩蛋角色登场。
- 网页不要放声音；页面内嵌内容控制在 16MB 内（参考成品约 11MB）。
- 用 Playwright 截图检查：开盒各时间点、再拆一盒、跳过、彩蛋全流程，看控制台没有报错。
- 发布为在线页面；本地另存一份 `index.html + figs/` 离线版。

## 6. 产品介绍
- 在线文档：一句话介绍、IP 形象特征表、款式表（含隐藏/彩蛋）、包装六面说明、开盒体验步骤、制作流程图、规格与文件位置。
- 展示网页：与盒子同一视觉（星空/主题色），首屏是可拖动的 360° 盒子 + 去开盒按钮，下面是全款卡片、彩蛋、盒面、开盒步骤、制作流程、规格。

## 7. 收尾整理
- 写 `00_目录说明.txt`（每个文件夹是什么、怎么用）和 `00_可删除清单.txt`（被取代的配色稿、旧脚本、带噪点的图等），删除交给用户自己确认。
- 网页源码打包成 `源码.zip` 存进用户文件夹。

## 沟通习惯
- 中文、简短；每步告诉用户「改哪一行、改成什么、大概要多久」。
- 长时间渲染建议一款一款来，渲完先让我抽查再继续。
