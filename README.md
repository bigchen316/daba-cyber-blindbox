# 大巴赛博盲盒 · Daba Cyber Blind Box

原创 IP「大巴」的第一套潮玩盲盒：8 款公仔（7 常规 + 1 隐藏）+ 彩蛋「超能大巴」。主题：**下班后，我在偷偷变强**。

## 制作流程

1. 2D 形象设计（AI 生图）
2. 3D 建模（混元3D）
3. 盒面设计（HTML 排版导出 PNG）
4. Blender 渲染（产品图、盒子 72 帧转盘、公仔 24 帧转盘）
5. 盲盒网页（拖动看盒、开盒星星炸开、公仔可转、集齐 8 款召唤彩蛋）
